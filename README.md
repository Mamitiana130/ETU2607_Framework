# 🧱 Mini Framework Inspiré de Spring Boot

Projet d’étude visant à concevoir un **framework minimaliste en Java EE**, dans le but de comprendre les mécanismes internes de frameworks comme **Spring Boot**.

## 📋 Description

Ce projet met en œuvre un framework léger développé en Java EE (Servlets + JSP), avec une architecture modulaire permettant de gérer l'authentification, les comptes utilisateurs et l’import de données.

Il simule certains comportements fondamentaux de Spring Boot pour en saisir le fonctionnement (routing, traitement des requêtes, injection simple, etc.).

## 🚀 Fonctionnalités principales

- 🔐 Login & Logout sécurisés
- 👤 Gestion de comptes utilisateurs (création, mise à jour)
- 📥 Importation de données via fichiers ou formulaire
- 🛠️ Structure modulaire inspirée de Spring Boot
- 🗂️ Organisation des contrôleurs et vues selon MVC
